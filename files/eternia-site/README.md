# Этерния — сайт мира

Статический сайт на чистом HTML/CSS/JS, без сборки и зависимостей.
Готов к публикации через **GitHub Pages**.

## Структура

```
index.html          — карта мира (главная страница)
rulers.html         — профили правителей
lore.html           — Серая Мгла и пограничные локации
css/style.css        — общие стили (типографика, карточки, навигация)
css/map.css           — стили только для карты
js/map-data.js        — ВСЕ данные регионов и точек интереса (текст, координаты)
js/map.js             — логика точек на карте и боковой панели
js/main.js             — мобильное меню, декоративные уголки
assets/sigils/*.svg    — геральдические эмблемы государств (используются и как маркеры на карте, и как «портреты» правителей)
assets/ornaments/*.svg — вензеля (уголки карточек, разделители)
```

## Как опубликовать на GitHub Pages

1. Создай репозиторий на GitHub и залей туда все файлы из этой папки (сохраняя структуру).
2. Зайди в **Settings → Pages**.
3. В разделе **Source** выбери ветку (`main`) и папку `/ (root)`.
4. Сохрани — через минуту сайт будет доступен по адресу вида
   `https://ТВОЙ_НИК.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`.

Никакой сборки не требуется — это обычные статические файлы.

## Как поправить точки на карте

Карта загружается по прямой ссылке из `js/map-data.js` (переменная `MAP_IMAGE_URL`).
Каждая точка задаётся в процентах от ширины/высоты картинки (`x`, `y`), поэтому
позиционирование не зависит от размера экрана.

Точки расставлены по текстовому описанию географии мира (Валория — север,
Сильвария — восток, Аквилла — юг, Кхор-Тул — крайний запад), но координаты —
приблизительные, потому что при подготовке сайта было невозможно посмотреть
на саму картинку. Скорее всего, их нужно будет чуть подвинуть.

**Режим калибровки.** Открой сайт с параметром `?calibrate`, например:

```
index.html?calibrate
```

Курсор превратится в перекрестие — кликай по нужным местам на карте, и в
правом верхнем углу появятся точные координаты `x` / `y` в процентах.
Их нужно вписать в соответствующий объект в `js/map-data.js`:

```js
{
  id: "valoria",
  x: 50,   // ← сюда
  y: 16,   // ← сюда
  ...
}
```

## Как добавить новый регион или локацию

Всё содержимое карты (кроме самой картинки) находится в одном месте —
`js/map-data.js`. Чтобы добавить точку, скопируй один из объектов массива
`ETERNIA_REGIONS` и заполни поля:

- `kind: "major"` — крупное государство (крупный маркер + герб, поля
  «население» / «правительство» / «правитель»).
- `kind: "minor"` — особая зона (малый маркер, только описание и опасность).

Правителей и лор-карточки на страницах `rulers.html` и `lore.html` можно
редактировать прямо в HTML — каждая карточка оформлена как отдельный блок
`<article class="card ornate ...">`.

## Цвета и шрифты

- Палитра: чёрный / фиолетовый / тёмно-коричневый — переменные заданы в
  начале `css/style.css` (`:root { --violet: ...; --umber: ...; }`).
- Заголовки — Cinzel Decorative, текст — Cormorant Garamond (обе через
  Google Fonts, подключены в `style.css`).

## Про эмблемы правителей

Готовых портретов персонажей не было, поэтому вместо стоковых лиц каждому
правителю подобрана геральдическая эмблема (шестерня — Валория, древо —
Сильвария, маска — Аквилла, рога — Кхор-Тул). Они лежат в
`assets/sigils/*.svg` и используются и на карте, и в профилях — если
захочешь заменить их на настоящие иллюстрации персонажей, просто подмени
файлы (или пропиши новый `<img>` в `rulers.html`).
